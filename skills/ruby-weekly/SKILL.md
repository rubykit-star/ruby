# Ruby weekly

1. In the vault, read the `Daily/` notes from the last seven days (file names start with the date).
2. Create `Research/Week <YYYY-Www>.md` from `Templates/Weekly.md` and fill in: value at the start and end of the week per wallet (from `total_usdg` in the frontmatter), the biggest transfers, and the lines the user wrote under **Notes**.
3. Link each day's note with [[wikilinks]]. Use only numbers from the notes.
